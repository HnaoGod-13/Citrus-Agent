# 报告撰写模块

## 模块定位

报告撰写模块由“报告服务”和“报告撰写 Skill”共同组成。

- 报告服务负责完成资料汇总、信息清洗、资料检索、大模型撰写、内容检查、Word 模板套用和文件输出。
- 报告撰写 Skill 负责让 Agent 理解用户什么时候要写报告、需要准备哪些信息、怎样调用报告服务、怎样继续修改，以及哪些内容必须提醒用户复核。
- 报告服务提供统一能力，Skill 负责让 Agent 正确使用这项能力。两者完成后，可以在现有工作台、知识图谱、数据库系统或其他项目中重复使用。

## 需要的信息

生成项目报告时主要使用以下内容：

- 当前任务和当前批次；
- 主体名称、产地、品种、批次号和数量；
- 糖度、酸度、水分、等级和检测资料；
- 目标产品、路线决策和工艺方案；
- 使用单位、承办部门、经办人员；
- 项目名称、建设区域、报告周期和项目目的；
- 用户上传的 Word 模板；
- 本地资料、知识图谱、数据库资料和互联网资料。

一份报告当前只使用一条正式提交记录，避免不同批次的信息混在一起。

## 完整流程

1. 用户在业务系统中填写或选择一条记录。
2. 草稿阶段只保存和检查信息，不生成正式分析结果。
3. 用户正式提交后，系统清洗字段并识别缺失、异常和无效信息。
4. 系统根据有效信息生成路线决策和基础工艺方案。
5. 用户补充项目名称、使用单位、地区、周期和报告目的等基本信息。
6. 系统自动从本地资料、知识图谱、数据库和互联网查询相关信息。
7. 系统区分用户事实、外部资料、分析建议和待确认内容，并为外部资料保留来源。
8. 大模型根据批次事实、决策结果、工艺方案和检索资料撰写完整项目报告。
9. 系统检查章节是否完整，是否出现没有依据的数字，来源是否清楚，工艺参数是否被误写成正式标准。
10. 系统读取用户 Word 模板，填入报告内容；没有模板时使用统一项目报告格式。
11. 用户在页面中预览报告，查看来源和待复核事项。
12. 用户导出可编辑 Word，继续审核、修改和定稿。

## 报告内容

项目报告主要包含：

1. 项目摘要；
2. 项目背景；
3. 项目建设必要性；
4. 原料与批次基本情况；
5. 产地与品种产业分析；
6. 市场需求与竞争环境；
7. 加工路线和工艺方案；
8. 项目建设内容；
9. 设备、产能和场地需求；
10. 质量安全与合规方案；
11. 副产物综合利用；
12. 投资估算与资金使用方向；
13. 运营模式和收益逻辑；
14. 实施计划；
15. 风险分析与应对措施；
16. 结论和立项建议；
17. 参考资料；
18. 待人工复核项。

## 资料和结论的处理方式

- 用户正式提交的产地、品种、批次和检测信息可以作为本项目的基础事实。
- 本地文献、知识图谱、数据库和互联网资料需要保留来源和时间。
- 路线、设备、试验和建设方案应写成分析建议，不能冒充已经确认的企业方案。
- 没有可靠依据的投资额、价格、收益率、市场规模和产能应写成待测算或待确认。
- 论文中的实验条件只能作为小试参考，不能直接变成生产标准。
- 报告结尾集中列出缺失资料和人工复核事项，便于业务人员继续补充。

## Skill 的作用

报告撰写 Skill 让 Agent 可以处理以下请求：

- 根据当前任务生成项目报告；
- 检查生成报告还缺少哪些信息；
- 根据用户要求修改某个章节；
- 补充市场、政策、产业或品种资料；
- 按单位 Word 模板重新生成；
- 查看资料来源和待复核事项；
- 导出可编辑 Word；
- 在同一任务下继续讨论和修改报告。

Skill 会先确认当前任务和记录，再调用报告服务。它不会自行编造数据，也不会在每个项目中重新实现检索、撰写和 Word 生成流程。

## 在其他项目中的使用方式

报告服务和 Skill 完成后，其他项目不需要重新开发一套报告系统，只需要把本项目中的字段与统一报告信息对应起来。

### 业务系统直接使用

业务系统可以在用户选择一条正式记录后，直接调用报告服务。系统把当前记录、分析结果和报告基本信息交给报告服务，随后获得报告预览、资料来源、复核事项和可编辑 Word。

适合固定表单、项目申报系统、产业管理平台和批量报告任务。

### Agent 使用 Skill

其他项目中的 Agent 安装报告撰写 Skill 后，可以理解“根据当前记录写项目报告”“把市场分析写详细一些”“按这个 Word 模板重新生成”等自然语言要求。

Agent 根据 Skill 检查当前任务、收集缺少的信息、调用报告服务，再把生成状态、报告内容和待复核事项返回给用户。

适合需要自然语言交互、连续修改和多轮沟通的项目。

### 知识图谱项目使用

知识图谱把当前实体及其关联的品种、产地、企业、产品、工艺、政策和文献资料交给报告服务。报告服务将图谱资料与互联网资料、项目填写信息一起组织成完整报告。

使用后可以从“查看一个实体”直接进入“生成这个实体对应的项目报告”，并保留图谱中的来源关系。

### 数据库项目使用

数据库系统把选中的业务记录转换成统一报告字段。用户在列表中选择一条记录后，即可生成完整报告，不需要把数据库内容复制到 Agent 对话框中。

适合生产记录、项目库、企业库、品种库、检测库和产业统计库。

## 在其他项目中能够达到的效果

- 同一套报告能力可以被多个项目共同使用，报告格式和质量保持一致。
- 不同项目只负责提供自己的数据，资料检索、大模型撰写、事实检查和 Word 输出由统一模块完成。
- 用户不需要重复录入系统中已经存在的信息。
- 报告可以同时结合业务记录、本地资料、知识图谱、数据库和互联网信息。
- 所有重要外部结论保留来源，缺少依据的内容自动进入待复核清单。
- 支持单位 Word 模板，最终输出可以继续编辑和正式申报。
- Agent 可以围绕同一任务继续解释、补充和修改报告，不会因为切换页面丢失当前批次。
- 后续调整报告章节、写作规则和 Word 格式时，只修改统一报告能力，各个接入项目可以同时获得更新。
