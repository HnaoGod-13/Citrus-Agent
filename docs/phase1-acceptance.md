# 第一阶段邀请制试点验收清单

这份清单用于上线前由产品负责人和管理员共同执行。每一步都应记录结果；出现失败时先停止发布，再修复并从失败步骤重新执行。

## 1. 准备环境

1. 进入 `streamlit-deploy` 目录，安装 `requirements.txt`。
2. 复制 `.env.example` 为 `.env`。
3. 本地验收设置 `CITRUS_ENV=development`、`CITRUS_AUTH_REQUIRED=true`、`CITRUS_DEV_AUTH_ENABLED=true`。
4. 生产验收必须使用 OIDC、PostgreSQL、私有对象存储和文件扫描服务；关闭 `CITRUS_DEV_AUTH_ENABLED`。
5. 执行 `python scripts/init_platform.py 管理员邮箱`，确认只允许执行一次。

## 2. 管理员和企业

1. 启动应用并用管理员邮箱登录。
2. 打开“设置 → 平台管理后台”，确认能看到默认试点企业。
3. 创建一个测试企业，重新登录后确认企业选择器能切换到新企业。
4. 在企业后台生成一个 `member` 邀请代码，确认页面只显示代码，不显示其他企业资料。

## 3. 邀请和权限

1. 用受邀邮箱登录，粘贴邀请代码并接受邀请。
2. 确认受邀邮箱和企业成员角色正确。
3. 用另一个未受邀邮箱登录，确认只能看到邀请入口，不能进入资料工作台。
4. 用不同邮箱接受原邀请，确认被拒绝。
5. 重复使用已接受邀请，确认被拒绝。
6. 使用过期邀请，确认被拒绝。
7. 分别验证 `owner`、`admin`、`reviewer`、`member`：
   - `owner` 和 `admin` 可邀请成员；
   - `reviewer` 可查看和审核，不能邀请或改成员权限；
   - `member` 可填写自己的资料，不能查看其他成员草稿；
   - 任何角色都不能访问其他企业资料。

## 4. 资料保存和审核

按以下顺序完成一条真实测试资料：

管理员初始化 → 管理员登录 → 创建企业 → 生成邀请 → 受邀邮箱登录 → 接受邀请 → 填写草稿 → 退出并重新登录 → 找回草稿 → 上传 PDF/PNG/JPG 附件 → 提交审核 → 管理员看到资料 → 审核退回 → 用户补充后重新提交 → 审核通过。

验收点：

- 草稿、版本号、更新时间和状态在重新登录后仍存在。
- 资料提交后生成任务编号，审核版本和资料版本一致。
- 附件可重新读取，内容校验值一致。
- 审核员不能审核自己创建的资料。
- 旧版本可查看，当前版本发生并发修改时会被拒绝覆盖。
- 导出的 JSON 只包含当前企业授权范围内的资料。

## 5. 管理后台和审计

1. 管理员查看企业成员、邀请记录、资料总览和待审核列表。
2. 审核资料，确认审核决定、意见、审核人和审核版本都被保存。
3. 下载“当前企业全部资料”，确认导出文件包含附件内容并且不包含其他企业记录。
4. 查看操作记录，确认登录、邀请、接受邀请、保存、提交、打开、导出和审核事件都有记录。
5. 用审核员账号确认成员和邀请信息只读，不能生成邀请。

## 6. 备份和恢复

1. 先保存至少一条草稿、一条已提交资料和一个附件。
2. 执行 `python scripts/backup_pilot.py`。
3. 确认生成的 zip 包包含 `manifest.json`、数据库快照、运行配置和附件，并且清单校验通过。
4. 执行 `python scripts/restore_pilot.py 备份文件.zip ./restore-check`。
5. 临时实例设置 `CITRUS_RUNTIME_DIR=restore-check/runtime`、`CITRUS_DATABASE_URL=sqlite:///restore-check/database/pilot.db`、`CITRUS_BLOB_DIR=restore-check/attachments`，再启动临时实例。
6. 确认恢复后的账号、企业、资料状态、历史版本和附件仍可读取。
7. 对非空目录恢复时不带 `--replace`，确认命令拒绝；仅在明确核对目标后使用 `--replace`。
8. 每日执行备份，每月在独立目录做一次恢复演练，并保存结果。

生产 PostgreSQL 备份会生成 `database/postgres.dump`，使用 `pg_restore` 在临时数据库恢复；不要把生产数据库直接覆盖恢复。

## 7. 发布门槛

以下条件全部满足才允许邀请真实试点企业：

- OIDC 登录已验证，邮箱未验证时会拒绝。
- PostgreSQL、私有对象存储和文件扫描服务已配置。
- 备份和恢复演练成功，并明确备份保留周期。
- 管理员、审核员和普通成员的权限测试全部通过。
- 隐私政策、数据保留期限、管理员联系人和正式域名已确认。
- 试点邀请、资料字段和附件大小限制已由业务负责人签字确认。
