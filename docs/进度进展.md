# 进度进展

## 项目现有功能

- 资料采集与批次管理：供应端和生产端填写各自对应的资料，支持草稿保存、正式提交和重新打开记录。必填信息支撑路线决策，选填信息补充分析依据；系统保留原始填写内容，并统一批次、日期、数量和质量指标的格式，识别缺失、异常与无效信息。
- 自动路线决策与工艺方案：正式提交后，系统按批次资料自动比较加工方向，给出首选、备选路线和推荐依据，并形成覆盖原料验收、分选、核心加工、稳定处理、包装和质控的基础工艺流程。资料不足或质量风险会在分析界面提示，用户无需在问答界面重复录入批次信息。
- 任务助手与资料依据：右侧助手围绕当前页面、任务和批次回答问题，可解释路线、工艺和风险，并承接同一任务的后续对话。系统支持本地文献检索、证据分级、加工参数依据和图片外观初筛，为分析结果提供可回查的资料线索。
- 报告撰写：目前一份报告对应一条正式提交的批次记录。用户补充项目名称、使用单位、承办部门、经办人、区域、周期和用途后，点击生成；系统汇总批次事实、路线与工艺方案，查询本地及互联网公开资料，由大模型撰写项目报告。报告包括项目摘要、产业与市场分析、建设与工艺方案、质量控制、投资方向、实施计划、风险和立项结论，并保留参考资料。网页支持预览及导出可编辑 Word，也可使用单位自有 Word 模板。
- 工作台与知识页面：用户可以查看当前批次、路线、工艺和报告；知识库提供文献浏览与检索，分析页面汇总会话、运行和样本情况。普通 Agent 对话仍可处理问答与图片分析，和工作台自动生成结果配合使用。
- 企业试点管理：已有邀请制账号、企业成员角色、企业范围内的资料保存与审核、附件管理、操作记录及资料导出能力，用于组织内部试点流程。

## 上次汇报后的新增优化

### 报告撰写与复用

- 报告正文调整为正式项目报告的表达方式：直接陈述项目事实、分析结果和立项建议，不再解释 Agent、大模型、数据清洗、评分、检索过程或任务编号等内部处理，也不设置“待补充”“待测算”式的写作占位章节。投资额、收益率、设计产能和检测结论没有依据时不编造；未来建设内容仍明确写为方案或实施要求。
- 报告质量检查进一步收紧：正式批次信息用于项目事实，路线与工艺用于建设方案，公开产业、品种、市场、政策和工艺资料用于扩展分析；外部结论保留来源编号与参考资料。区域产业数据不写成项目订单或收益，批次数量不写成设计产能，文献中的实验参数不直接写成正式生产标准；不符合正文表达要求时会重新生成。
- Word 排版按示例统一：`[1]`、`[2]` 等引用为真正的上标；中文正文及页眉页脚使用宋体，英文和数字使用 Times New Roman；小标题三号、左对齐且不空两格，正文与目录小四；表格五号、左对齐、无底色、三线表，跨页时不重复表格标题或表头。已按完整流程修订沃柑加工项目示例 Word。
- 形成 `project-report-writing` Skill，规定如何使用项目事实、查找资料、组织章节、保留引用、检查正式报告表达和导出 Word，供不同项目复用同一套写作规则。
- 形成 `report-writing-module-builder` Skill，指导在其他网站建设完整的报告撰写板块，包括项目表单、正式提交、任务关联、生成与失败状态、报告预览、来源展示、Word 下载以及返回页面后的结果恢复。前一个 Skill 管报告内容，后一个 Skill 管网页模块的搭建与接入。
- 已形成统一报告数据格式和独立服务接口的本地实现，可接收项目资料、业务记录、路线、工艺与已有来源，返回报告正文、来源和可编辑 Word。知识图谱、数据库或其他网站接入时，可按统一格式映射各自数据，并在原项目页面呈现报告功能。

### 其他功能与体验

- 企业试点从单纯填写资料扩展为邀请制使用：支持受邀邮箱凭一次性邀请加入企业、切换所属企业，区分填报成员、资料审核员、企业管理员和负责人；账号在当前企业范围内查看和处理资料，管理员可管理邀请和成员权限。
- 资料流转加入审核环节：成员可保存草稿、正式提交并查看版本；审核人员可通过、退回补充或判定不通过，并留下审核意见。附件与记录按企业范围管理，资料可按单条或整个企业导出，操作记录便于回查；同时具备试点资料与附件的备份和恢复能力。
- 已提交或重新打开的批次分析结果可在路线决策和工艺方案专页复用；用户在专页点击生成后，可查看当前批次的质量概况、候选路线与工艺阶段，减少重复录入和旧结果覆盖当前批次的情况。
- Agent 页面增加赣南脐橙 NFC 果汁和新会茶枝柑果皮综合利用两个可运行示例。点击后可从示例批次进入路线评估或工艺展示，并看到批次数量、关键指标、资料状态及推荐方向；示例切换时会清除上一个示例的展示结果，避免混用。
- 右侧任务助手的图片提问接入视觉模型。提交图片时会保留本轮上传内容，避免表单刷新后图片丢失；图片分析结果与当前页面、任务和批次关联，继续在右侧对话区呈现。
- “新建业务任务”现在会清除上一任务的选中批次、分析结果和报告状态，重新显示供应端/生产端选择入口，避免新任务沿用旧批次信息。
- 对话输入区补充发送状态和时间显示，生成中有明确的思考提示；示例卡片、侧边导航、滚动和页面间距做了统一调整，使连续查看批次、路线、工艺与报告时更易定位当前内容。
